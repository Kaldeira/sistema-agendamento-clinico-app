# sistema-agendamento-clinico-app

Este é um projeto acadêmico desenvolvido para fins de estudo e prática de desenvolvimento Android.

## 📱 Sobre o projeto
Aplicativo mobile voltado para o gerenciamento de agendamentos em uma clínica, permitindo o cadastro e gerenciamento de usuários, médicos e consultas.

## 🎯 Objetivo
O objetivo principal é aplicar conceitos de desenvolvimento Android, banco de dados e arquitetura de aplicações móveis.

## 🛠️ Tecnologias utilizadas
- Java
- Android Studio
- SQLite
- XML

## 📌 Status
Projeto em desenvolvimento acadêmico.
